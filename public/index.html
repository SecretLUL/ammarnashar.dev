03 The rules

What all three have in common

winmedic.exe
Sotto.zip
MCmodsLoader.exe

Just download it

One file. No installer wizard, no account, no "sign up to continue". WinMedic is a single .exe (or one winget command), and MCmodsLoader doesn't even need .NET installed.

  • updatesgithub.com
  • modsmodrinth.com
  • speech modelshuggingface.co
  • trackingnowhere

Your stuff stays yours

No tracking, no telemetry. Sotto can transcribe completely offline, and WinMedic only goes online for updates, connection checks and clean system files during a repair.

  1. Restore point
  2. Repair
  3. Undo anytime

Safe to try

WinMedic sets a restore point before it touches anything. Sotto warns you before a recording gets overwritten. MCmodsLoader clears out old mod versions so nothing crashes.

Always up to date

All three check GitHub for new versions and update in one click. WinMedic and Sotto check every download against its SHA-256 first.

Open source

Everything's on GitHub: WinMedic under GPL-3.0, Sotto and MCmodsLoader under MIT. Read the code, fork it, break it, send a fix.

04 How I work

Think first. Build fast. Trust nothing.

  1. 01

    Think first

    Before I write any code, I figure out the data, the edge cases and the stuff that must never break. That's where good software actually gets decided.

  2. 02

    Build fast

    AI models like Claude and Gemini take care of the boring parts and the boilerplate. That keeps the loop from idea to working build really short.

  3. 03

    Trust nothing

    AI code gets reviewed like a stranger's pull request: race conditions, memory safety, compiler warnings. Then it has to survive real hardware. WinMedic's checks, for example, are tested against output from real Windows installs.
